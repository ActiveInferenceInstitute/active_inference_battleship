# Organization ownership and version 0.5.0

The public repository is [ActiveInferenceInstitute/active_inference_battleship](https://github.com/ActiveInferenceInstitute/active_inference_battleship). It was transferred from the personal account `ActInfInstitute` on October 26, 2026, retaining its repository identity, commits, and earlier releases. Current source, package metadata, citation, manuscript, and site use the organization URL.

The dashboard is served at [the organization Pages site](https://activeinferenceinstitute.github.io/active_inference_battleship/), with the [paper reader](https://activeinferenceinstitute.github.io/active_inference_battleship/paper/). Repository redirects preserve earlier source/release links; GitHub Pages does not redirect the former account site automatically.

The [version 0.5.0 manuscript archive](https://doi.org/10.5281/zenodo.23676081) supersedes [the unchanged version 0.4.0 deposit](https://doi.org/10.5281/zenodo.23670188). Earlier deposits, dated audit records, protocol provenance, scientific traces, and original lecture production remain historical artifacts. Their identifiers are preserved rather than relabeled as newly produced evidence. See [publication details](PUBLICATION.md) for current artifacts and verification limits.

This update improves interface explanation and animation; it does not add experimental cases or change the Bayesian model, one-shot objective, or 24-comparison statistical design.
