The R4 manuscript candidate passed both independent review lanes on October 24, 2026. Root accepts the reviewed bytes for local integration. This is bounded manuscript acceptance, not a public release or scientific efficacy claim.

## What changed

- Ten display equations are automatically numbered and cross-referenced in PDF, DOCX, and HTML. Four definitions, two propositions, and one example use the actual template's formalism counters. Inserting another formalism changes subsequent numbers through the rendering pipeline; numbers are not painted into figures or patched into binaries.

Each plate combines a large figure with its title, explanation, and margins. The opening is also present before the HTML table of contents.
- Eight whole dashboard DOM crops retain their capture provenance, replay, and analysis. Figure generation checks those bindings. The HTML supplies descriptions and full-size links; screenshots remain scientific illustrations rather than interactive controls.
- Native MathJax commands retain their actual preferences, keyboard behavior, and speech/explorer features. Guarded submenu replacement cleans up the prior posted submenu; preference Escape delegates to native Close even after keyboard focus leaves the editor. Browser checks await actual native rendering readiness before sending input.

## Verification and its limits

The producer ran 25 manuscript tests, lint, typecheck, edition validation, real PDF/DOCX/HTML rendering, and source-bound text/image paint checks. The template receipt binds 258 actual Python imports and the separate formalism filter. PDF has 16 pages; the actual DOCX's LibreOffice projection has 17. All pages were inspected, including their final content.

Both independent reviewers individually opened all 722 PNGs: 16 PDF pages, 17 Word-projection pages, 218 ordinary HTML frames, 225 native Chrome 200% frames, 234 native-menu frames, eight dashboard crops, and four illustrations. Each reported zero before/after custody drift. Fresh independent positive probes covered six width/theme configurations, 18 preference cycles, delayed worker completion, the original keyboard/navigation scenario, and stale-response supersession. Eight intended regression controls rejected. Invalid harness attempts were retained and excluded from those controls.

The earlier R3 B three-Escape failure remains a real historical record whose exact focus cause is unknown. Current trace-based outside-focus dismissal, native submenu lifetime, and readiness checks have independently rejecting controls. Their acceptance does not establish every possible asynchronous interleaving. One B-review harness attempt installed a dependency into its own external cache; it was excluded, and its corrected control used `--no-install`. Project packages and lockfiles were unchanged.

The review did not rerun a new scientific study or efficacy experiment. Original mathematical display interiors, core/model inputs, protocol, results, and bibliography retain their documented continuity. Exact inference remains bounded to the sampled, biased fleet-label catalog; planning is one-shot, with no parameter learning. The concurrent live GNN initializer edit was preserved: the 48 compiled parser bindings were verified against the pinned source snapshot, not represented as a fresh pass against dirty live upstream.

Acceptance covers the frozen Chrome reader, PDF, and LibreOffice projection. It does not certify native Microsoft Word, Safari, physical devices, screen readers, offline manuscript use, public-clone readiness, publication, or educational efficacy. The future public repository is [ActInfInstitute/active_inference_battleship](https://github.com/ActInfInstitute/active_inference_battleship); a Zenodo PDF DOI remains a release plan. No publication or DOI action was performed.
