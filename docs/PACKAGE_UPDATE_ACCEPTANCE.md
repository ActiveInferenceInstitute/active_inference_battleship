## Limits

Inference is exact conditional on a biased finite fleet catalog. Planning is one step, sensor noise is subjective, and parameters are not learned. Cross-engine floating-point differences can change near-tied opponent actions, so replay version one is not a promise of identical Node/Bun/browser reconstruction. Retain the producing runtime separately and compare histories before treating a reconstruction as the original run.

Rendered acceptance concerns the supplied Chrome catalog and PDF/LibreOffice DOCX projections. It does not establish native Microsoft Word, Safari, physical-device, screen-reader, fresh offline-installation, deployment, publication, scientific efficacy, or unrestricted Battleship correctness. Unmeasured timing/native checklist items remain unqualified.
